# Entertainment-Catalog
An API to catalog movies a user is watching and track titles available across multiple streaming services. The core component of this system is to utilise another api in order to assits with information that can otherwise be hard to aquire or costly. And later on use that information that is aquired to utilise it as desired without external interfearens.

## Current state
The current state of the api is that the API's core components works as intended, with a docker and swagger setup in order to run it through a more streamlined process as well as verify the systems functionalites through a more transparent methord. A user update the database, and then search for different entertainments that are accessable on a certain platform for specific regions. As well as if one search for a movie or series, one can get access to which platforms and regions the entertainment source is acceaable on. With the understanding that the database has been updated for that region
